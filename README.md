# Боты типа «Глаза Бога»: как выбрать подходящий

Если ищете похожий бот или альтернативу, начните с собственного запроса. У вас есть номер телефона, Telegram `@username` или числовой ID? От этого зависит, какой поиск нужен. Затем проверьте, как бот показывает дату и контекст найденной записи.

## Три вопроса перед выбором

1. **Что можно отправить?** Удобно, когда бот явно показывает поддерживаемые форматы, а не заставляет угадывать команду.
2. **Что видно в ответе?** Ищите признаки, по которым можно сверить совпадение: ID, имя, дату и тип записи.
3. **Куда ведёт ссылка?** Открывайте бота через действующую страницу с понятным адресом. Не вводите пароль или код входа на странице, которая выглядит как копия Telegram.

Наш поисковый бот принимает номер, ник и Telegram ID. При совпадении он может показать связанные исторические записи. Их состав зависит от источника и конкретного запроса.

## Как сравнить результаты

Похожее имя в двух ответах ещё не означает, что речь об одном аккаунте. Сравните Telegram ID, даты и дополнительные детали. Старый номер может перейти другому человеку, а ник может измениться. Если один сервис показывает только короткий фрагмент, проверьте, достаточно ли данных для вашего вывода.

Не переносите личные сведения из результата в открытый репозиторий или комментарии. Для выбора бота обычно хватает сравнения поддерживаемых запросов и понятности ответа.
